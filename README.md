# Real-Time Java Chat Application

A client-server chat application developed using Java Socket Programming.

## Features

- Client-server communication using TCP sockets
- Multiple client connections
- Username-based connection
- Real-time message handling
- Server-side client handling using threads
- Maven-based Java project

## Technologies Used

- Java
- Socket Programming
- TCP/IP
- Multithreading
- Maven
